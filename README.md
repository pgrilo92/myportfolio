# Joaquim Grilo - AI Expert Portfolio

Modern portfolio website showcasing AI expertise for banks and businesses in Lusophone Africa.

## Features

- **Multilingual**: Portuguese (primary, Angolan variant), French, and English
- **Modern Stack**: Next.js 14 with static site generation
- **AI Features**: 
  - Interactive banking assistant demo (client-side)
  - Animated AI visual effects
  - No API keys or backend required
- **SEO Optimized**: Pre-rendered pages, OG tags, sitemap, hreflang tags
- **Mobile-First**: Fully responsive design
- **Performance**: Optimized images and assets

## Languages

- **Portuguese (Angolan)**: Primary language with European Portuguese spelling and Angolan context
- **French**: For Canadian connection
- **English**: International audience

## Development

```bash
npm install
npm run dev
```

Visit http://localhost:3000

## Build & Deploy

```bash
npm run export
```

The `out/` directory contains the static site ready for deployment.
